# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/naraya07pedro-spec/ledgercore/security/advisories/new) when available. Include the affected commit, a private synthetic reproduction and the impact. If private reporting is disabled, ask for a private contact through the repository without posting exploit details or credentials.

LedgerCore V1 supports a local synthetic demonstration. Consult the [threat model](docs/threat-model.md) for trust assumptions, including database-owner and application-role access. Rotate exposed credentials promptly and omit all secrets from reports.
